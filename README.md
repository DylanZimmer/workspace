Workspace - AI-Powered Chat and Note System

Hosted on trackedSpace.netlify.app

Workspace is a chat-based application powered by Gemini that saves customizable AI-written notes. Users can define object templates, generate objects from these templates, and train specialized model instances to act as domain-specific experts. The project was inspired by my research on Ramsey numbers: for example, I use it to generate and analyze graphs, then guide the model in exploring patterns too large for humans to process directly.

Features
- Chat-based interface for interacting with AI instances
- User-defined object templates and automated object generation
- Specialized model instances tailored to specific tasks
- Secure storage of AI-generated notes and objects
